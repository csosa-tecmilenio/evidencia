# Evidencia - Sistema de Administración de Citas Médicas

## Instalación y Configuración
1. Clonar el repositorio: `git clone https://github.com/csosa-tecmilenio/evidencia.git`
2. Asegurarse de tener instalado JDK 11 o superior.
3. Compilar el proyecto utilizando la herramienta de IntelliJ para generar el archivo FAT JAR:
   `mvn clean package`

## Uso del Programa
Ejecutar el archivo JAR desde la consola:
`java -jar citas-medicas-1.0.0.jar`
